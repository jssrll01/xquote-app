# xqoute-app

XMARKET quotations & receipts — standalone React + Vite PWA sharing the XMARKET Supabase DB.

## Features
- Access-code gate (`VITE_QUOTE_ACCESS_CODE`)
- Create receipt with customer info, items, tax, discount, notes
- Live totals (subtotal, tax, discount, grand total)
- Live A4 receipt preview
- Export: PDF (A4), Thermal 80mm, Excel (.xlsx), CSV, PNG
- Receipt history with search
- Installable PWA (same icon as XMARKET)
